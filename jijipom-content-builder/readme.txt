jijipom テーマ向けのコンテンツを画面上で組み立て、ZIP でエクスポートするプラグインです。

== 概要 ==

管理画面「jijipom コンテンツ」で、トップ・サービス・会社概要・お問い合わせ・
プライバシーポリシーの各ページの内容を、実際の見た目をプレビューしながら入力できます。

1. ビルダーで内容を入力（画像・動画・YouTube、各ブロックの表示/非表示も設定可）
2. 「ZIPをエクスポート」で jijipom-content.zip をダウンロード
3. 書き出した ZIP を jijipom テーマの「外観 > コンテンツ取込」から取り込むと、
   各ページ設定（カスタマイザー）と固定ページにまとめて反映されます

ZIP は別サイトへ持って行って取り込むこともできます。

フロントページに設置したい場合は、固定ページ・投稿にショートコード
[jijipom_builder] を貼り付けてください。入力とエクスポートはブラウザ内で
完結し、サーバーには保存されません。

※取り込み（反映）機能は jijipom テーマ側（外観 > コンテンツ取込）にあります。
　このプラグインはビルダーとエクスポートを担当します。

== 変更履歴 ==

= 1.7.0 =
* サービスページの各サービス項目に「リンク先URL」を設定できるようにした。
  URLを入れるとカード全体がリンクになる(取り込みで jijipom に反映)。

= 1.6.0 =
* 「下書き保存」「下書き読込」を追加。入力途中の内容をファイル(jijipom-draft.json)
  に保存し、後で(別の端末・ブラウザでも)読み込んで続きから編集できる。
  ※従来どおりブラウザへの自動保存も継続。

= 1.5.7 =
* 左の入力エリアを太い枠(アクセント色)で囲み、「入力フォーム」の見出しを付けて
  入力欄だと分かりやすくした。

= 1.5.6 =
* ショートコードに全幅オプションを追加: [jijipom_builder width="full"]。テーマの
  本文最大幅(--wide-width)に縛られず画面幅いっぱいに広げられる(フルワイドの
  ページ向け)。

= 1.5.5 =
* 印刷時のヘッダーが全幅になり実サイトとズレる不具合を修正。ヘッダー内容を
  本文と同じ最大幅・中央寄せに揃えた(画面プレビューも本文と揃うよう改善)。

= 1.5.4 =
* 埋め込み時に iframe の高さ計測が無限に繰り返され、右領域の高さが確定しない
  不具合を修正(通知高さをコンテンツ実高さに固定し、両側で変化時のみ更新)。

= 1.5.3 =
* 「印刷 / PDF」で白紙になる不具合を修正。iframe 埋め込み時でも確実に印刷
  できるよう、プレビュー(全ページ)を別ウィンドウに書き出してから印刷する方式に
  変更。

= 1.5.2 =
* プレビューのヘッダー(スマホ表示)を実テーマに合わせて調整。ナビを隠すだけ
  でなく、テーマと同じハンバーガーメニュー(☰)を表示し、CTAボタンとともに
  右寄せにした。

= 1.5.1 =
* 「基本設定」タブを①トップの前に追加し、サイト基本・フォント・ソーシャルの
  3項目をそこへ移動(全ページ共通の設定として整理)。

= 1.5.0 =
* トップに「ソーシャルメディア」設定を追加(X/Instagram/Facebook/Threads/
  TikTok/YouTube のURL＋表示順)。URLを入れたSNSがフッターにアイコン表示され、
  取り込みで jijipom のソーシャル設定に反映される。

= 1.4.1 =
* プレビューのフッターを jijipom 実際のフッター(footer.php)と同じ構成に修正
  (明るい背景・ブランド+ナビ・下段にコピーライトとソーシャル)。全ページに表示。

= 1.4.0 =
* トップの「サイト基本」に、サイトタイトル・サイトタイトル画像(ロゴ)・
  フォント設定(全体/見出し/本文/フォーム)を追加。取り込み時に jijipom へ反映
  (タイトル=サイト名、ロゴ=カスタムロゴ、フォント=テーマ設定)。
* プレビューの仮URLを example.com に変更。

= 1.3.0 =
* プレビューに PC / スマホ の表示切替を追加。各デバイス幅で描画し、パネル幅に
  合わせて自動縮小するので、PC版・スマホ版のレイアウトを正しく確認できる。

= 1.2.0 =
* ショートコード [jijipom_builder] を追加し、フロントページにも設置可能に。
* ビルダーの iframe を中身の高さに自動リサイズするようにし、入れ子の
  スクロールバー(プレビュー部分の内側スクロール)を解消。

= 1.1.0 =
* 取り込み(インポート)機能を jijipom テーマ側へ移動。プラグインはビルダーと
  ZIP エクスポートに専念するようにした。
