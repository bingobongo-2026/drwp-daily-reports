jijipom テーマ向けのコンテンツを画面上で組み立て、ZIP でエクスポートするプラグインです。

== 概要 ==

管理画面「jijipom コンテンツ」で、トップ・サービス・会社概要・お問い合わせ・
プライバシーポリシーの各ページの内容を、実際の見た目をプレビューしながら入力できます。

1. ビルダーで内容を入力（画像・動画・YouTube、各ブロックの表示/非表示も設定可）
2. 「ZIPをエクスポート」で jijipom-content.zip をダウンロード
3. 書き出した ZIP を jijipom テーマの「外観 > コンテンツ取込」から取り込むと、
   各ページ設定（カスタマイザー）と固定ページにまとめて反映されます

ZIP は別サイトへ持って行って取り込むこともできます。

フロントページに設置したい場合は、固定ページ・投稿にショートコード
[jijipom_builder] を貼り付けてください。入力とエクスポートはブラウザ内で
完結し、サーバーには保存されません。

※取り込み（反映）機能は jijipom テーマ側（外観 > コンテンツ取込）にあります。
　このプラグインはビルダーとエクスポートを担当します。

== 変更履歴 ==

= 1.11.0 =
* サービスページ「提供サービス」のカード並びをテーマと同じ2列グリッドに
  修正。従来は独自の折り返しで、4件目だけ下段中央に孤立して表示されて
  いた（テーマは元から2×2グリッドで、この並びはプレビューだけの症状）。
  カードの余白・見出しサイズもテーマの .svc-card と同値に。
* ボタンをテーマと同じデザインに総点検。
  - トップのサービスボタン: 枠線だけのゴースト風 → テーマと同じ
    塗り（アクセント色）に。ゴーストスタイルは廃止。
  - すべてのボタンの余白をテーマの .button と同じ .65em/1.3em に、
    文字サイズも継承（17px）に統一。
  - ヘッダーボタンの余白・文字サイズもテーマの .header-cta と同値に。
  - 未入力プレースホルダをボタン上では半透明白に（青地の灰色は不可読）。
* プレビューの基本文字サイズをテーマと同じ 17px・行間1.8に。ナビ・
  ロゴの文字サイズもテーマの実寸に統一。
* お問い合わせフォームの項目を設計できるようになった。
  - 種類は5つ: テキスト / テキストエリア / ドロップダウン /
    チェックボックス / ラジオボタン。
  - 項目名・選択肢（カンマ区切り）を自由に設定、追加・削除・並び替え可。
  - 既定は従来と同じ「お名前・メールアドレス・ご相談内容」。
  - プレビューに即時反映。書き出しZIPの contact_form に仕様として同梱
    され、実サイトでフォーム（Contact Form 7 等）を作るときの設計書になる。

= 1.10.1 =
* メインビジュアルのプレビューをテーマの実装に完全一致させた。
  - キャッチコピーの折り返し幅: 56ch 制限 → テーマと同じ全幅
    (最大1080px)。長いキャッチコピーの改行位置が実サイトと同じになる。
  - text-wrap:balance と文字の影を削除 (テーマには無い)。
  - サブテキストを 1.25rem に (テーマの --fs-lg と同じ)。
  - ボタンの影を削除し、要素間隔を flex gap 1.2rem に (テーマと同じ)。
  - 左寄せ/右寄せの配置も flex の align-items で切替 (テーマと同じ挙動)。

= 1.10.0 =
* jijipom テーマ 1.19 の設定に同期。ビルダーからテーマと同じ内容を設定
  できるようになった。
  - 配色: メインカラー（アクセント色。ホバー濃色はテーマ側で自動計算）
  - レイアウト: 全体の幅・本文の幅・メインビジュアルの高さ・トップページ
    のセクション並び順（プレビューにも反映）
  - フッター情報: 住所・電話番号（従来は固定サンプルで編集不可だった）
  - トップ: サービスセクションの見出し、ブログ/会社紹介セクションの
    表示切替、ヒーローの背景画像2・3/切り替え間隔/文字とボタンの配置/
    ボタンの背景色・文字色
  - お問い合わせ: フォームのショートコード
* プレビューをテーマの実寸に合わせて調整。
  - コンテナ幅 1000px → 1080px（テーマの --wide-width と同じ）
  - セクションの上下余白・見出しサイズ・ヒーローの高さ(PC 520px/スマホ
    320px相当)・ページタイトルのサイズをテーマの clamp 値のPC/スマホ
    評価値に統一
  - ヒーローのオーバーレイをテーマと同じ rgba(0,0,0,.3) のフラットに
  - ブログを4カラム・4記事に（テーマの標準は4列）
* 取り込みには jijipom テーマ 1.19.1 以上が必要です（新設定の取込対応）。

= 1.9.1 =
* ライブプレビューが画面からはみ出し、右端(ヘッダーのボタン付近)が
  見切れる不具合を修正。プレビュー列を minmax(0,1fr) にして、中の
  デバイス枠(固定1140px)より狭くできるようにした。従来は列が1140pxまで
  広がってしまい、自動縮小(zoom)がほとんど効かない状態だった。
* あわせて全体の最大幅を 1240px → 1640px に拡大。広い画面ではPC表示を
  縮小なし(等倍)で確認できる。
* 埋め込み(ショートコード)で親が iframe をリサイズした場合など、ウィンドウ
  リサイズを伴わない幅変更にも ResizeObserver で追従するようにした
  (幅が変わったときだけ再計算し、高さ変化では発火させない)。

= 1.9.0 =
* 「基本設定」にヘッダーボタンの設定を追加。これまでビルダーからは設定できず、
  取り込み対象にも入っていなかったヘッダーの問い合わせボタンを、ビルダー上で
  文言・リンク先URL・アイコン・背景色・文字色まで指定できるようにした。
* ヘッダーボタンの左隣に並ぶ「サブボタン」を追加(同じく文言・URL・アイコン・
  背景色・文字色を指定可能)。資料請求・電話などの導線を2つ並べられる。
* アイコンは11種類(なし/メール/電話/吹き出し/カレンダー/書類/ダウンロード/
  地図ピン/人/右矢印/外部リンク)から選択。ライブプレビューに即反映される。
* 色は「テーマ標準に戻す」で未指定に戻せる。未指定のときは jijipom テーマの
  配色がそのまま使われる。
* ※反映には jijipom テーマ 1.18.0 以降が必要。
