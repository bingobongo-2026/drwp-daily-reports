jijipom テーマ向けのコンテンツを画面上で組み立て、ZIP でエクスポートするプラグインです。

== 概要 ==

管理画面「jijipom コンテンツ」で、トップ・サービス・会社概要・お問い合わせ・
プライバシーポリシーの各ページの内容を、実際の見た目をプレビューしながら入力できます。

1. ビルダーで内容を入力（画像・動画・YouTube、各ブロックの表示/非表示も設定可）
2. 「ZIPをエクスポート」で jijipom-content.zip をダウンロード
3. 書き出した ZIP を jijipom テーマの「外観 > コンテンツ取込」から取り込むと、
   各ページ設定（カスタマイザー）と固定ページにまとめて反映されます

ZIP は別サイトへ持って行って取り込むこともできます。

フロントページに設置したい場合は、固定ページ・投稿にショートコード
[jijipom_builder] を貼り付けてください。入力とエクスポートはブラウザ内で
完結し、サーバーには保存されません。

※取り込み（反映）機能は jijipom テーマ側（外観 > コンテンツ取込）にあります。
　このプラグインはビルダーとエクスポートを担当します。

== 変更履歴 ==

  スクロールバー(プレビュー部分の内側スクロール)を解消。
