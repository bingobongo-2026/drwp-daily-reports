jijipom テーマ向けのコンテンツを画面上で組み立て、ZIP でエクスポート／取り込みできるプラグインです。

== 概要 ==

管理画面「jijipom コンテンツ」で、トップ・サービス・会社概要・お問い合わせ・
プライバシーポリシーの各ページの内容を、実際の見た目をプレビューしながら入力できます。

1. ビルダーで内容を入力（画像・動画・YouTube、各ブロックの表示/非表示も設定可）
2. 「ZIPをエクスポート」で jijipom-content.zip をダウンロード
3. 「取り込み」でその ZIP を読み込むと、jijipom の各ページ設定（カスタマイザー）
   と固定ページにまとめて反映されます

ZIP は別サイトへ持って行って取り込むこともできます（テーマ本体の改修は不要）。

== 取り込みで反映されるもの ==

* jijipom のカスタマイザー設定（メインビジュアル、トップの各セクション、
  サービス／会社概要／お問い合わせ／プライバシーの各テンプレートの領域）
* 固定ページの作成・更新（サービス／会社概要／お問い合わせ／プライバシー／ホーム）
  とテンプレートの割り当て、トップページの設定（任意）

色・フォント・ヘッダー/フッター・SNS などビルダーに無い項目は上書きされず、
そのまま残ります。
