=== jijipom child ===
Requires at least: 6.0
Tested up to: 6.5
Requires PHP: 7.4

jijipom テーマ用の子テーマです。

== これは何のためのもの ==

親テーマ(jijipom)を直接編集すると、テーマを更新したときに変更が
すべて消えてしまいます。子テーマにカスタマイズを置いておけば、
親テーマを更新しても消えません。

== 使い方 ==

1. 親テーマ「jijipom」を先にインストールしておく(有効化はしなくてよい)
2. この子テーマ(jijipom-child)をインストールし、こちらを**有効化**する
3. 「外観 > カスタマイズ」の設定内容は親テーマと共通で、そのまま使えます

※親テーマが入っていないと有効化できません。

== カスタマイズの置き場所 ==

* CSS … style.css の下部に追記します。親テーマの style.css の「後」に
  読み込まれるので、同じセレクターを書けば上書きできます。
  親テーマは配色・文字サイズ・余白などを :root のカスタムプロパティ
  (デザイントークン)で管理しているので、多くの場合はそこを上書きするのが
  いちばん手軽です。

* PHP … functions.php に追記します。親テーマの functions.php が
  置き換わるわけではなく、「子 → 親」の順で両方が読み込まれます。

* テンプレート … 差し替えたいファイルを親テーマから同じファイル名で
  コピーし、この子テーマフォルダーに置くと、そちらが優先されます。
  (例: header.php, footer.php, templates/page-contact.php)
  フォルダー構成も親テーマと同じにしてください。

== 補足 ==

* theme.json はこの子テーマには置いていません。置かない場合は親テーマの
  theme.json がそのまま使われます。子テーマに theme.json を作ると親の設定を
  完全に置き換えてしまうため、一部だけ変えたいときは CSS で調整するほうが
  安全です。

* 親テーマは自身の style.css を get_stylesheet_uri() で読み込んでいます。
  この関数は「有効なテーマ」の style.css を指すため、子テーマを有効にすると
  親の style.css が読み込まれません。そのため、この子テーマの functions.php
  で親の style.css を明示的に読み込んでいます(この処理は消さないでください)。
