FAQ

よくある質問

既存の WordPress サイトに導入できますか？
はい、プラグインを有効化するだけで、既存サイトに日報マンの管理メニューが追加され、記事は WordPress の投稿として公開されます。テーマは選びません。
AI 機能には別途料金がかかりますか？
OpenAI / Anthropic の API キーを「AI 設定」に入力していただきます。プロバイダ側の従量課金（記事1本の生成あたり数円程度）が別途発生します。
現場の社員はスマホで日報を送れますか？
はい。専用のモバイル最適化フォームがあり、写真撮影・添付・送信まで片手で完結します。送信した日報は事務所側のレビュー待ちに入ります。
個人情報の取り扱いはどうなっていますか？
公開記事化の前に顧客名・電話番号・メール・郵便番号を自動検知して警告します。ワンクリックで「Y様」「○○○-○○○○-○○○○」のような形式に自動マスクできます。
過去の日報を消したい場合はどうすれば？
建設業法の保存義務と内部不正対策の観点から、完全削除は管理者のみ・アーカイブ後30日経過後のみ可能です。それまでは「アーカイブ」で一覧から非表示にできます。
ライセンス検証はどのように動きますか？
独立したライセンスサーバーが Ed25519 の署名付き応答を返し、プラグイン側で検証します。応答を改ざんしても機能解放にはつながりません。
無料体験はできますか？
はい。お問い合わせフォームから無料体験ライセンスをお申し込みください。すぐに発行してメールでお送りします。
